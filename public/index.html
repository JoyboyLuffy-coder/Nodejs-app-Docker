Deploy in 3 Steps

01

Build Image

docker build -t nexus-app .

Creates an optimised Alpine-based image with only production dependencies.

02

Run Container

docker run -d -p 3000:3000 \
  --name nexus-app nexus-app

Starts the container in detached mode, mapping port 3000 on host to container.

03

Or Use Compose

docker compose up -d

Spins everything up with one command including health checks and restart policy.

What's Inside

🐳

Multi-Stage Dockerfile

Separate build and runtime stages. Final image uses Alpine for minimal size.

🏥

Health Endpoint

GET /health — returns JSON status, uptime, and timestamp. Used by Docker HEALTHCHECK.

📦

docker-compose.yml

Full compose config with restart policy, env vars, port mapping, and health check.

🔒

.dockerignore

Excludes node_modules, .git, logs, and dev files from the Docker build context.

⚙️

ENV Configuration

PORT and NODE_ENV configurable via environment variables or .env file.

📄

Static File Server

Express serves everything in /public with SPA fallback routing built in.
